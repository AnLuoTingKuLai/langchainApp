# 安全规则

## 敏感信息

- 不在源码、注释、日志、Mock 数据中写入真实密钥、令牌、账号或密码。
- 环境变量放在 `.env` / `.env.*`，不要把敏感值硬编码到业务文件；`.env` 已在 `.gitignore` 中。
- 本项目为本地熟悉 LangChain 用：前端通过 `VITE_` 前缀读取密钥（会打进浏览器包），**仅本地学习，勿公网部署**。
- 提交前留意新增配置和调试输出，避免泄露内部地址或凭证。

## 请求与鉴权

- 翻译等模型调用由页面直接走 `src/ai` 的 LangChain 链。
- HTTP 请求走 `src/api/axios.ts` + `interceptor.ts`；`VITE_API_BASE_URL` 可选。
- 不在页面组件里直接拼密钥或模型配置（密钥只通过 `VITE_` 环境变量注入）。
- 修改登录、权限、路由守卫前必须检查调用链和影响范围（若项目后续引入鉴权）。

## 前端安全

- 不直接渲染未经处理的 HTML；确需使用 `v-html` 时先说明原因并做输入来源确认。
- URL、路由参数、查询参数进入业务逻辑前要明确来源和类型。
- 文件下载、外链跳转等能力要避免拼接不可信输入。

## 日志

- 生产环境不要输出敏感数据。
- 调试日志不要长期保留。
